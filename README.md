# 모바일 도구 접속 페이지

비공개 저장소에 있는 모바일 페이지들에 들어가는 접속 페이지입니다. 이 저장소에는 접속 화면(`index.html`), 페이지 목록(`apps.js`), 서비스 워커(`sw.js`)만 있고, 각 페이지의 본체는 비공개 저장소에 있습니다.

| 페이지 | 경로 | 비공개 저장소 |
| --- | --- | --- |
| 나이아가라 모바일 | `/niagara/` | `kdw471/niagara-mobile` 의 `niagara/` |
| MindFlow 마인드맵 | `/mindmap/` | `kdw471/mindmap-mobile` 의 맨 위 |

## 동작

1. 접속 화면에 GitHub 토큰을 넣으면, 목록의 각 저장소를 그 토큰으로 읽을 수 있는지 GitHub API로 확인합니다. 읽을 수 있는 페이지에 그 토큰을 붙여 이 기기의 브라우저에 저장합니다.
2. 열 수 있는 페이지의 "열기"를 누르면 그 경로로 이동합니다.
3. 서비스 워커가 그 경로의 요청을 가로채, 같은 파일을 비공개 저장소에서 받아 돌려줍니다. 받은 파일은 커밋별로 기기에 캐시하고, 페이지를 열 때마다 최신 커밋을 확인합니다.
4. 토큰이 만료되거나 권한이 없어지면 접속 화면으로 돌아가고, 그 페이지의 토큰과 캐시를 지웁니다.

지금 목록의 저장소는 모두 `kdw471` 계정 소유라서, kdw471 계정에서 두 저장소를 고른 읽기 전용 fine-grained 토큰 하나로 모두 열 수 있습니다. fine-grained 토큰은 한 계정이 가진 저장소만 고를 수 있으므로, 나중에 다른 계정의 저장소를 추가하면 그 계정의 토큰을 따로 넣으면 됩니다.

## 페이지 추가

`apps.js`에 한 줄을 넣습니다. `prefix`는 이 사이트의 경로, `root`는 비공개 저장소 안의 폴더입니다. 페이지는 상대 경로만 써야 합니다(`/`로 시작하는 주소는 이 사이트의 맨 위를 가리키게 됩니다). 같은 사이트에서 열리므로 브라우저 저장소(localStorage 등)를 페이지끼리 함께 씁니다. 키 이름이 겹치지 않게 하세요.
