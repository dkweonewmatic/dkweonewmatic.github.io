# 나이아가라 모바일 접속 페이지

나이아가라 모바일 편집기에 들어가는 접속 페이지입니다. 편집기 본체는 비공개 저장소에 있고, 이 저장소에는 로그인 화면(`index.html`)과 서비스 워커(`sw.js`)만 있습니다.

## 동작

1. 접속 페이지에서 GitHub 토큰을 입력하면, 그 토큰으로 비공개 저장소를 읽을 수 있는지 GitHub API로 확인합니다.
2. 통과하면 토큰을 이 기기의 브라우저 저장소에 넣고 `/niagara/`로 이동합니다.
3. 서비스 워커가 `/niagara/...` 요청을 가로채, 같은 경로의 파일을 비공개 저장소에서 받아 돌려줍니다. 받은 파일은 커밋별로 기기에 캐시합니다.

접근 허가는 GitHub의 저장소 권한으로 정해집니다. 비공개 저장소의 협업자가 만든 토큰만 통과합니다.

## 고지

이 프로젝트는 Epic Games와 관련이 없는 개인 도구입니다. Unreal, Unreal Engine, Niagara는 Epic Games, Inc.의 상표 또는 등록 상표입니다.
