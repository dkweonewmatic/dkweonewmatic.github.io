편집기를 여는 중…

이 브라우저는 서비스 워커를 지원하지 않아 편집기를 열 수 없습니다. 최신 Chrome이나 Safari를 사용하세요.

토큰 만드는 법
  1. GitHub의 새 fine-grained 토큰 페이지를 엽니다.
  2. Repository access에서 Only select repositories를 고르고 niagara-mobile을 선택합니다.
  3. Permissions의 Repository permissions에서 Contents를 Read-only로 둡니다. 다른 권한은 주지 않습니다.
  4. 만든 토큰을 위 칸에 붙여 넣습니다. 토큰은 이 기기의 브라우저에만 저장됩니다.

다른 사람에게 허가하려면 niagara-mobile 저장소에 협업자로 추가하고, 그 사람이 자기 토큰을 만들게 하세요. 허가를 거두려면 협업자에서 빼면 됩니다.
